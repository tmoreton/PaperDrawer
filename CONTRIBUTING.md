# Contributing to PaperDrawer

Bug reports and focused feature discussions are welcome. Never include real scans, OCR text, account numbers, health information, or other sensitive data in an issue or test fixture.

Report security or privacy vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in a public issue.

Please open an issue before preparing a code contribution. To keep ownership and future commercial licensing clear, unsolicited pull requests are not accepted. Code contributions require a separate written contributor agreement arranged with the maintainer before work is merged.

For an agreed contribution, build the app for iPhone and iPad simulators and verify the affected flow before submitting it. Contributions must not add analytics, tracking, advertising, accounts, cloud document processing, or production credentials.
