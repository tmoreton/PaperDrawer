# Security Policy

## Supported versions

Security and privacy fixes are applied to the latest version of PaperDrawer available on the App Store.

## Reporting a vulnerability

Please report suspected security or privacy vulnerabilities privately by emailing `tmoreton89@gmail.com`. Do not open a public issue for a vulnerability.

Include the PaperDrawer version, device and operating-system version, expected impact, and concise reproduction steps. Use fictional test content only. Do not send real scans, recognized text, account numbers, health or identity information, Apple signing credentials, or other secrets.

You should receive an acknowledgment within seven days. Reports are investigated and handled according to their severity. PaperDrawer does not currently operate a bug-bounty program.
